    NominalInstrument ¤

    NominalInstrument(
    name: str,
    connection_config: ConnectConfig | None,
    publishers: list[Publisher] | None = None,
    background_config: BackgroundDaemonConfig | None = None,
    **kwargs,
)

    Base class for all Nominal instrument interfaces.

    This class provides common functionality for instrument communication, data publishing, and background worker daemon management. Subclasses should implement instrument type specific behavior.

    Parameters:

    • name ¤

      (str) –

      A name to identify this instrument instance. Used in channel naming and published data.

    • connection_config ¤

      (ConnectConfig | None) –

      Connection configuration for instruments that require a communication interface (e.g., SCPI/VISA). Set to None for instruments that use vendor-specific libraries.

    • publishers ¤

      (list[Publisher] | None, default: None ) –

      List of publishers to send data to when measurements or commands are executed. Defaults to None.

    • background_config ¤

      (BackgroundDaemonConfig | None, default: None ) –

      Configuration for the background worker daemon. If None, a default configuration is created. Defaults to None.

    • **kwargs ¤

      –

      Optional keyword arguments used as tags throughout the life of the instrument. These tags are applied to the Measurement and Command objects and can be utilized by publishers like NominalCorePublisher as added metadata.

      Special keyword arguments: dataset_rid (str): If provided, automatically creates and adds a NominalCorePublisher with the specified dataset RID. Assumes a Nominal 'default' credential is stored on disk.

    name = name

    open ¤

    open()

    Open a connection to the instrument.

    This method establishes communication with the instrument if a connection configuration has been provided. If no data_handler exists (connection_config was None), this method does nothing.

    close ¤

    close()

    Close the connection to the instrument and clean up resources.

    This method stops the background worker thread, closes the instrument connection, and closes all publishers. It should be called when done using the instrument to ensure proper cleanup of resources.

    start ¤

    start()

    Start the background worker thread.

    This method creates and starts a daemon thread that periodically executes all registered background daemon functions. If the thread is already running, this method does nothing. The thread will continue running until stop() is called.

    stop ¤

    stop()

    Stop the background worker thread.

    This method signals the background worker thread to stop and waits for it to complete. If the thread is not running, this method does nothing.
